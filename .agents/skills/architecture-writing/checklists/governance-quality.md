# Governance Quality Checklist

- [ ] Principles are approved
- [ ] Rules are explicit
- [ ] Rule scope is clear
- [ ] Evidence source is defined
- [ ] Thresholds are policy-backed
- [ ] UNKNOWN is distinct from FAIL
- [ ] Exceptions have expiry
- [ ] Exceptions have owner and approval
- [ ] CI behavior is deterministic
- [ ] Governance does not invent architecture decisions
