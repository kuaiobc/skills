# Full Architecture Review Workflow

1. Frame scope and decision.
2. Collect requirements, repository/runtime evidence.
3. Build/update architecture model.
4. Run intelligence: diff, smells, boundaries, impact.
5. Identify drivers and quality scenarios.
6. Plan and execute reasoning where needed.
7. Evaluate alternatives and trade-offs.
8. Review security, reliability, operations, data, deployment.
9. Review migration and rollback.
10. Run governance checks.
11. Reconcile diagrams/ADR/design.
12. Publish findings and actions.
