# Evolution and Inheritance Map

The reconstruction preserves the cumulative intent of the architecture-writing evolution.

- Early foundation: architecture story, trade-offs, quality attributes, ADRs, review, migration, diagrams.
- Workflow expansion: repository analysis, boundaries, option generation, decision matrix, multi-audience output, evolution.
- Agent contract: structured decision model, discover/analyze/design/generate/validate, evidence and validation.
- Tooling layer: scanner, dependency analyzer, architecture graph, agent orchestration, ADR sync, artifact generation.
- Intelligence layer: diff, smells, boundary candidates, driver inference, change impact, confidence.
- Governance layer: principles, rules, fitness functions, compliance, exceptions.
- Reasoning engine: method selection/composition, SCQA/MECE/decision methods, evidence, contradiction, sensitivity.
- Runtime layer: planner, executor, plan DSL, execution state, lineage, reproducibility.

The key inheritance rule is that each later layer augments the earlier layer. No execution layer is allowed to delete the semantic responsibilities of the writing, modeling, design, or governance layers.
