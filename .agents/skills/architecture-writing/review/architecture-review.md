# Architecture Review

Review in layers:

1. problem framing
2. requirement/driver coverage
3. architecture model and boundaries
4. alternatives/trade-offs
5. quality attributes
6. security/trust
7. data consistency/ownership
8. failure/recovery
9. operability/observability
10. deployment/scaling
11. migration/rollback
12. governance

Findings should contain severity, evidence, affected decision, consequence, and recommendation/validation.
