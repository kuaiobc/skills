# Audience Adaptation

The semantic model stays stable while presentation changes.

- executive: drivers, outcomes, risks, decision, cost
- architect: boundaries, trade-offs, quality attributes, evolution
- developer: interfaces, dependencies, flows, failure behavior
- operator: deployment, observability, alerts, rollback, runbooks
- security: trust boundaries, data flows, controls, threats
- reviewer: evidence, alternatives, assumptions, validation

Do not create contradictory audience-specific decisions.
