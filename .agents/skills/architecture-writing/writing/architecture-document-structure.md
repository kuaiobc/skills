# Architecture Document Structure

A complete architecture document may contain:

- Executive Summary
- Context and Goals
- Scope / Non-Goals
- Requirements
- Constraints and Assumptions
- Architecture Drivers / Quality Scenarios
- Current State
- Target Architecture
- Key Flows
- Data / Ownership
- Security / Trust Boundaries
- Reliability / Failure Handling
- Deployment / Operations
- Alternatives and Trade-offs
- Decision / ADR links
- Risks
- Validation Plan
- Migration Plan
- Open Questions

Use only sections that matter; completeness is not the same as length.
