# Reasoning Planner

Build a plan from the architecture question and available evidence.

1. classify the problem;
2. identify the reasoning objective;
3. identify candidate methods;
4. define inputs and evidence requirements;
5. order dependent steps;
6. define outputs and stop conditions;
7. define contradiction/sensitivity checks;
8. define the recommendation output and human decision point.

Do not plan a method merely because it is available. Use the smallest useful method set.
