# MECE

## Purpose
Create useful, non-overlapping categories that make a complex architecture problem inspectable.

## Procedure
1. Define the partition question.
2. Select one classification dimension.
3. Create sibling categories at the same abstraction level.
4. Check overlap.
5. Check material omissions.
6. Mark residual/unknown items instead of forcing a category.

MECE is a practical structuring heuristic, not a guarantee of logical completeness.
