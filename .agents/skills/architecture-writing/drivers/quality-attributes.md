# Quality Attributes

Treat quality attributes as scenarios rather than adjectives.

`Stimulus → Context → Response → Measure → Target → Priority`

Cover when relevant:
- performance
- scalability
- availability
- reliability
- resilience
- consistency
- security
- maintainability
- testability
- observability
- operability
- cost
- portability
- interoperability
- deployability

Map each material quality scenario to architecture tactics and validation evidence.
