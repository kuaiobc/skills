# Composition

Composition normalizes request, context, audience, language, profile, preset,
dimensions, anti-AI policy, and defaults into Style IR. The behavior compiler
then produces Behavior IR. Merge semantics and precedence are normative in
`merge-rules.yaml` and `precedence.yaml`; run the sequence in `workflow.md`.

Scalar values are selected by authority; compatible lists and maps merge;
semantic tensions use interactions; irreconcilable behaviors use explicit
conflict resolution. Preserve provenance through each step and freeze both IRs
before drafting.
