# Analyze

Extract document type, audience, purpose, constraints, source material, and desired voice. Identify missing information that materially affects correctness; otherwise proceed without unnecessary questions.

Choose the primary profile from the requested deliverable and purpose, not the
topic alone. Resolve the subject domain and audience independently. For
example, a technical blog uses the blog profile with an engineering audience;
a technical design document uses the technical profile.

When the output is Chinese, apply the user-facing Chinese rules in
`audience/engineer.md` if the profile is `technical` or the audience is
engineer. A blog or report takes those rules only when its audience is
engineer.
