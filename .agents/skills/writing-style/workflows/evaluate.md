# Evaluation Workflow

1. Freeze Effective Style IR.
2. Freeze Behavior IR.
3. Select evaluation mode.
4. Evaluate task and correctness.
5. Evaluate audience and language.
6. Evaluate behavior coverage.
7. Evaluate style fidelity.
8. Evaluate anti-AI.
9. Detect drift.
10. Produce scorecard.
11. Produce ranked issues.
12. Decide whether rewrite is necessary.
