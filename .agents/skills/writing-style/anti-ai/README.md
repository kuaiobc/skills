# Anti-AI

Anti-AI is orthogonal to style. Remove filler, generic transitions, mechanical
symmetry, inflated abstraction, fake experience, translationese, Chinglish,
and bureaucratic language. Do not replace them with artificial human quirks.
Simulate sound judgment through specific claims, useful uncertainty, and
concrete evidence; never invent personal experience.

The language profiles describe locale-specific realization. Anti-AI checks
remain subordinate to factual correctness, task completion, and explicit user
requirements.
