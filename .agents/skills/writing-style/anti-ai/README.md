# Anti-AI Writing

Anti-AI is a quality filter, not a request to write badly.

## Core rule

Remove language that exists mainly because a language model likes predictable rhetorical patterns.

Do not remove a phrase merely because it is common. Judge its function, repetition, and fit.

## High-value checks

1. Generic opening — replace broad claims with the actual subject, event, tension, or question.
2. Empty correctness — remove sentences that are true but add no decision-relevant information.
3. Formulaic transitions — replace paragraph-announcing connectors with causal or topical transitions.
4. Symmetry — vary sentence and paragraph shapes when uniformity adds no value.
5. Buzzword stacking — translate abstract nouns into mechanisms, examples, or consequences.
6. Fake humanity — never invent first-person experience, emotion, or anecdote.
7. Performative uncertainty — do not repeatedly say "可能" or "我觉得" just to sound humble.
8. Forced colloquialism — do not add slang merely to escape AI detection.
9. Over-structured prose — use headings and lists when they help the reader, not because a template expects them.
10. Generic conclusion — end with the implication, decision, unresolved question, or next action that actually follows from the piece.
