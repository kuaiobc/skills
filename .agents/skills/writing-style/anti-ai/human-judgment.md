# Human Judgment

The strongest anti-AI signal is not imperfection. It is judgment.

Prefer:
- why this option was selected
- what was rejected
- what trade-off was accepted
- where the recommendation stops applying
- what remains uncertain
- what the writer would inspect next

A useful test: "Could any generic language model produce this paragraph without knowing this author's decision or observation?" If yes, look for an opportunity to add concrete reasoning.
