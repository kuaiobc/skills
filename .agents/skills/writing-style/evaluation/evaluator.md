# Evaluator

## Input

- Effective Style IR
- Behavior IR
- Draft
- Evaluation mode

## Process

1. Check correctness and task completion.
2. Check audience.
3. Check language.
4. Check structure.
5. Check behavior coverage.
6. Check style fidelity.
7. Check anti-AI.
8. Check drift.
9. Produce issues.
10. Rank issues by severity and priority.

## Important

A missing low-weight behavior is not automatically a defect.

An over-applied high-weight behavior can be a defect.

Evaluation must consider both presence and restraint.
